读懂 UserService 的四个位置

先读小课 01，再用这页检查自己是否还记得。

想观察每一步传递的值、s 的用途和计数变化，打开发短信执行演示。

代码位置它负责什么
type UserService interface {…}列出使用方可以依赖的方法要求。
type userService struct {…}定义具体数据类型和字段。
func (s *userService) SendCode(…) error方法体执行真实业务；s 是接收此次调用的指针。
func NewUserService(…) UserService普通创建函数；创建具体对象，并按接口返回。
 
func NewUserService(service *Service) UserService {
    p := &userService{Service: service}
    return p
}
  • userService{…}：创建结构体值。
  • &userService{…}：得到指向结构体的指针，类型是 *userService。
  • Service: service：字段名 → 参数值。嵌入的 *Service 字段默认名为 Service。
  • 编译期间，编译器检查 return 中的 *userService 是否满足接口要求；运行时返回的接口值携带该指针。
  • 接口变量调用方法，执行其携带的具体值的实现。

当前方法用指针接收者，删去 & 后结构体值不满足接口。大小写表示包外可见性；接口与结构体的区别来自 interface / struct 关键字。

s 是方法本次调用的接收者变量，携带实例指针；s.field 访问那份实例数据。方法关联类型，多个实例共享方法逻辑，由接收者确定本次操作哪个实例。
