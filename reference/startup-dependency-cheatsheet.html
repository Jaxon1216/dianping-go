Cheat sheet

启动、依赖组装与退出

面试或读源码前，用两分钟恢复完整链路。

主链

配置 → 日志 → Redis / DB → Query
→ Service → Handler → Gin / HTTP Server
→ App.Run → ListenAndServe

三组必须区分

声明 vs 执行

wire.go 声明 provider。

wire_gen.go 执行普通构造调用。

注册 vs 处理

s.GET 在启动期登记路由。

Handler 在请求匹配后执行。

启动成功 vs 完整清理

Redis/DB 初始化失败会 panic。

但退出时尚未显式关闭二者。

HTTP 停机 vs 应用停机

HTTP Shutdown 最多等待 5 秒。

后台消费者没有跟随生命周期取消。

源码入口

  1. cmd/server/main.go：启动总入口。
  2. cmd/server/wire/wire_gen.go：真实构造顺序。
  3. internal/server/http.go：中间件与路由注册。
  4. pkg/app/app.go：信号与 Server 生命周期。
  5. pkg/server/http/http.go：监听与 5 秒 Shutdown。

面试表达

项目在启动期由 Wire 生成的普通 Go 代码完成依赖组装，基础设施先创建， 再注入 Service、Handler 和 HTTP Server。路由也在启动期注册。 App.Run 启动 Server 并监听退出信号；当前仅 HTTP 请求有 5 秒优雅停机窗口， DB、Redis 与后台消费者的统一清理尚未闭环。
