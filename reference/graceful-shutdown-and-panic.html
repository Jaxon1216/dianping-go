优雅停机、Shutdown 与 panic

退出是生命周期的一部分；关键是计划内退出还是异常终止。

一句话

优雅停机：先关闭新工作入口，在期限内等已有工作完成并释放资源，然后退出。

项目链路

SIGINT / SIGTERM
→ App.Run
→ srv.Stop()
→ HTTP Shutdown(5s)
→ 等待在途请求
→ cleanup
→ 进程退出

panic 四步

  1. 停止当前函数的正常执行。
  2. 执行已注册的 defer。
  3. 沿调用栈向上展开。
  4. 未 recover 时打印栈并非零退出。

当前边界

  • HTTP 在途请求最多等待 5 秒。
  • Wire cleanup 当前为空。
  • DB 与 Redis 没有显式关闭。
  • 秒杀消费者没有接入 App 的取消信号。
